# Tejaswi Salvi — Vercel-style portfolio

A minimal, dark, Vercel-inspired portfolio built with Next.js, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy to Vercel

Push this folder to GitHub and import the repository into Vercel. No special build configuration is required.

### Before publishing
The resume lists LinkedIn and GitHub but does not include their URLs, so the footer currently leaves those as placeholders. Replace the two placeholder spans in `app/page.tsx` with your actual profile links.
